SOLIS — COFFEE SHOP ORDERING & DELIVERY
=========================================

THE FOUR APPS
  shop/      Shop dashboard (live orders, menu, drivers, delivery companies, reports, settings)
  customer/  Customer ordering app  - installable on the phone
  driver/    Driver app             - installable on the phone
  courier/   Delivery company app   - for outsourced delivery companies

All four share the same data. An order placed in the customer app appears
instantly in the shop, the driver app and the delivery company app, and every
status change shows up live for the customer.

1) TRY IT ON THIS COMPUTER
   Double-click START-HERE.html and open the apps in separate browser tabs.
   In this mode the data stays on this one computer.


2) CONNECT ALL PHONES LIVE (free Firebase database)
   a. Go to https://console.firebase.google.com  ->  Add project  ->  name it (e.g. Solis)
   b. Build -> Firestore Database -> Create database -> Production mode -> choose a location
   c. Firestore -> Rules tab -> paste the contents of firestore.rules -> Publish
   d. Build -> Authentication -> Get started -> Sign-in method -> enable "Anonymous"
   e. Project settings (gear icon) -> Your apps -> Web (</>) -> register the app
      -> copy the firebaseConfig values
   f. Open config.js and replace   window.SOLIS_FIREBASE = null;   with:

      window.SOLIS_FIREBASE = {
        apiKey: "....",
        authDomain: "....",
        projectId: "....",
        storageBucket: "....",
        messagingSenderId: "....",
        appId: "...."
      };

   The shop dashboard header then shows "● Live" instead of "● This device only".


3) PUT IT ONLINE (free GitHub Pages) so customers and drivers can install it
   a. Create a new GitHub repository (e.g. solis) and upload ALL files and folders
      from this folder (keep the same structure).
   b. Repository -> Settings -> Pages -> Source: "Deploy from a branch" -> main / root -> Save
   c. After a minute your links are:
        Customers:          https://YOUR-NAME.github.io/solis/customer/
        Drivers:            https://YOUR-NAME.github.io/solis/driver/
        Shop:               https://YOUR-NAME.github.io/solis/shop/
        Delivery companies: https://YOUR-NAME.github.io/solis/courier/
      (The shop's Settings tab also shows these links with Copy buttons.)
   d. In Firebase -> Authentication -> Settings -> Authorized domains,
      add  YOUR-NAME.github.io


4) INSTALL ON A PHONE
   Android (Chrome): open the link -> tap "Install app" in the app, or menu ⋮ -> Install app
   iPhone (Safari):  open the link -> Share -> Add to Home Screen
   Each app installs separately with its own icon (Solis, Solis Driver, ...).


5) BRANDING FOR A CLIENT
   - Shop name, address, phone, delivery fee, LBP rate: Settings tab in the shop dashboard
   - App names on the home screen: the "name" lines in each manifest.webmanifest
   - Icons: replace the PNG files in assets/icons (same file names)


HOW OUTSOURCED DELIVERY WORKS
   Settings -> "Who delivers your orders?"
     Own drivers only / Delivery company only / Own drivers + delivery company
   On an order, press Dispatch -> Delivery company -> Send request.
   The company sees it in its app, assigns a rider, marks picked up and delivered.
   You can also send the same request on WhatsApp from the order card.
   Optional: Settings -> auto-send every accepted delivery order to one company.
   Reports -> Delivery company balances shows cash they collected vs. fees owed.
